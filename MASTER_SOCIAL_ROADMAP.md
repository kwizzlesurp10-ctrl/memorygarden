# Memory Garden — Master Social Roadmap
**Goal**: Evolve Memory Garden into the definitive social memory sharing & growing platform.

- [x] Memory sharing links
- [x] Always-visible Plant button (just fixed)
- [ ] Public gardens & Explore page
- [ ] User profiles (basic)

## Phase 3: Discovery & Community

- [ ] Trending memories & gardens
- [ ] Search public memories

## Phase 4: Advanced Social Features
- [ ] Follow gardeners
- [ ] Garden subscriptions / notifications
- [ ] Beautiful shareable memory cards (Open Graph ready)
- [ ] Cross-platform sharing (X, Instagram, WhatsApp)
- [ ] Collaborative planting sessions (real-time)

## Phase 5: Polish & Virality
- [ ] Onboarding that creates a public garden by default
- [ ] Profile customization + badges
- [ ] Garden themes & seasonal events
- [ ] Achievement system tied to social actions
- [ ] Mobile-first PWA experience

## Success Metrics
- Users can easily plant, share, and visit others' gardens
- Social growth loops (visiting → watering → leaving reflections → growing together)
- High shareability of individual memories and entire gardens
